# Open-Source Plan

NimblyBase should provide a useful open-source core while keeping managed provider operations sustainable.

## Proposed Open-Source Components

- MCP server tools
- CLI
- JavaScript SDK
- shared API schemas
- local development adapter
- example Skills
- example templates
- documentation
- sample apps

## Managed Service Components

The hosted NimblyBase service may include:

- hosted control plane
- billing
- provider credentials
- Entri integration
- Cloudflare provisioning
- Neon provisioning
- Fly/Railway provisioning
- super admin dashboard
- production-grade usage and cost intelligence

## Why This Is Useful

The open-source core should allow teams to:

- understand how agent infrastructure is modeled
- run local demos
- build their own MCP-compatible integrations
- contribute reusable Skills
- inspect API contracts
- reproduce the architecture

## License Direction

Apache-2.0 is recommended for the initial repository because it is permissive, business-friendly, and suitable for infrastructure projects.
