# Contributing

NimblyBase is currently in early planning and prototype stage.

## Development Direction

Initial contribution areas:

- MCP tool design
- CLI command design
- Cloudflare D1/R2/Workers adapters
- Neon Postgres adapter
- Entri domain flow adapter
- documentation
- example Skills
- sample apps

## Principles

- Agent-facing tools must be safe, auditable, and idempotent.
- Provider operations must emit activity and usage events.
- Destructive actions should require explicit approval.
- The open-source core should remain useful without requiring the hosted service.

Implementation setup will be added after the first prototype is scaffolded.
